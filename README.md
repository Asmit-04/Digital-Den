# 🛒 Digital Den

**Digital Den** is a full-featured e-commerce web application for buying electronic products. It includes a modern UI, secure authentication, cart management, payment gateway integration, and more.

## 🚀 Features

- 🧾 User Authentication (Login/Signup)
- 📦 Product Listings & Categories
- 🛍️ Add to Cart / Remove from Cart
- 💳 Checkout with **Stripe Payment Gateway**
- 🔐 Protected Routes for Secure Transactions
- 📜 Order History Tracking
- 🌐 Fully responsive frontend

## 🛠️ Tech Stack

**Frontend:**  
- React.js  
- React Router  
- Context API / Redux
- Tailwind CSS

**Backend:**  
- Node.js  
- Express.js  
- MongoDB  
- Stripe API (Payment Integration)  

## 💻 Getting Started

1. Clone the repo  
2. Navigate to both `backend/` and `frontend/` folders and run:
   npm install
   npm start
3. Connect to your MongoDB database  
4. Make sure to create separate `.env` file for both the frontend and backend, and add all required key.
5. Visit `http://localhost:3000` to use the app  

## 📦 Deployment

You can deploy the frontend on **Netlify** or **Vercel**, and the backend on **Render**, **Railway**, **Vercel**, or **MongoDB Atlas + Node hosting**.
